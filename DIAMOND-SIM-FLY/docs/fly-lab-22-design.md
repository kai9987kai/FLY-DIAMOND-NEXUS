# Fly Lab expansion — 20 September 2026

The requested outcome is a more capable, inspectable fly-agent sandbox with six additional brain modules, richer environmental variation, more God Mode actions, denser graph presentation, and a Supermix graft that leaves ongoing work untouched.

The default expands from 16 to 22 modules. The existing 16-module engine remains a comparison arm. New modules cover plume integration, climate response, threat anticipation, route memory, uncertainty-driven exploration and social coordination. These are bounded functional heuristics, not six reconstructed biological brains. Graph dimensions, activity meters, the matrix editor and saved state must all agree. Coupling is normalized so adding connections cannot simply amplify every vote.

Weather, wind, temperature, humidity, terrain, shelter, resources and moving predators interact with observations and movement costs. A seeded environment owns this state and its random generator. God Mode edits and presets operate through the same environment contract as ordinary simulation steps. State restoration validates the complete candidate before swapping the live run.

Supermix connects through a localhost sidecar. The sidecar reads a fixed, bounded selection of logs, never checkpoints, training datasets or mutable model pointers. It cannot launch, stop or pause jobs. True model advice requires an already-serving endpoint that explicitly identifies v92 and guarantees inference will not load a model. Telemetry alone is never labeled inference. Advice uses finite four-action vectors, a maximum 35% influence, expiry in simulation ticks and existing legal-action checks. Request latency cannot renew its lifetime. External arrivals make live sessions non-deterministic; stored advice can be replayed, while further network arrivals are separate interventions.

Validation combines focused regression tests, the existing suite, JavaScript/HTML checks, browser controls and screenshots, exact snapshot continuation, and matched-seed 22-versus-16 experiments. An improvement claim is limited to measured configurations; richer functionality does not establish universal superiority.

The new module uses the functional label “plume integration” rather than claiming to implement a specific identified neuron type.
